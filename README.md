## Аутентификация (Login)

Чтобы получить доступ к нашим ущербным ресурсам, сначала нужно получить JWT-токен.

*   **Эндпоинт:** `POST /api/auth/login`
*   **Тело запроса (Body):**
    ```json
    {
        "username": "akishkin",
        "password": "sarbaev"
    }
    ```
*   **Успешный ответ (200 OK):**
    ```json
    {
        "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJleHAiOj..."
    }
    ```

Полученный `token` необходимо сохранять и передавать при каждом последующем запросе к защищенным эндпоинтам в заголовке `Authorization` или любом другом, лол.

**Пример заголовка:**
`Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJleHAiOj...`
