🚀 КАК ИСПОЛЬЗОВАТЬ:

  1. cd frontend
  2. npm start
  3. Откроется http://localhost:3000
  4. Нажми "Вход" в header
  5. Введи credentials или создай новый аккаунт
  6. Готово!

📋 ТРЕБОВАНИЯ BACKEND:

  ✓ Backend на http://localhost:8080
  ✓ POST /api/auth/login - принимает username, password
  ✓ POST /api/auth/register - принимает username, email, password
  ✓ Возвращает JSON с полем "token"
  ✓ При ошибке: JSON с полем "message"
