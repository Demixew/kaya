# Frontend - Страница логина/регистрации

## ✅ Что было сделано

### 1. **Новый компонент LoginRegister**
- Создан полноценный компонент с поддержкой логина и регистрации
- Красивый UI с градиентом (#667eea → #764ba2)
- Поддержка переключения между режимами (логин ↔ регистрация)

### 2. **API Интеграция**
```javascript
// Логин
POST http://localhost:8080/api/auth/login
{
  "username": "akishkin",
  "password": "sarbaev"
}

// Регистрация
POST http://localhost:8080/api/auth/register
{
  "username": "username",
  "email": "email@example.com",
  "password": "password"
}
```

### 3. **Token Management**
- Token автоматически сохраняется в `localStorage` при успешной аутентификации
- Token отправляется в заголовке `Authorization: Bearer <token>`
- При логауте token удаляется

### 4. **Навигация**
- Кнопка "Вход" на header отправляет пользователя на страницу логина
- Кнопка "Регистрация" в Hero разворачивает модальное окно (или можно переделать)
- Кнопка "Уже есть аккаунт?" на Hero отправляет на страницу входа
- Кнопка "Назад" на странице логина возвращает на главную

### 5. **Валидация**
- Username: обязательное поле
- Email (при регистрации): обязательное + формат email
- Password: минимум 6 символов
- Confirm Password: должны совпадать
- Все ошибки отображаются красиво

### 6. **User Status**
- После успешного входа в header показывается "✓ Вход выполнен"
- Кнопка "Выход" позволяет разлогиниться
- Token сохраняется и проверяется при загрузке приложения

## 🔧 Как использовать

1. **Запуск фронтенда:**
```bash
cd frontend
npm start
```

2. **API должен быть запущен** на `http://localhost:8080`

3. **Тестирование:**
   - Нажми "Вход" в header → откроется страница логина
   - Нажми "Начать бесплатно" → откроется модальное окно регистрации
   - Заполни форму и отправь

## 🎨 Дизайн

- **Цвета:** Фиолетовый градиент (#667eea - #764ba2)
- **Font:** Используется системный шрифт
- **Responsive:** Работает на мобильных и ПК
- **Animations:** Красивые анимации при загрузке

## ⚠️ Важно

- Убедитесь, что backend API работает на `http://localhost:8080`
- API должен возвращать `token` в JSON формате: `{ "token": "..." }`
- При ошибке API возвращает: `{ "message": "ошибка" }`
